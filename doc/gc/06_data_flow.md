# GC 数据流与处理流程

## 1. 整体数据流

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           GC 数据流概览                                  │
└─────────────────────────────────────────────────────────────────────────┘

┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  Incremental │    │    Global    │    │   Snapshot   │
│  Checkpoint  │    │  Checkpoint  │    │   Metadata   │
└──────┬───────┘    └──────┬───────┘    └──────┬───────┘
       │                   │                   │
       ▼                   ▼                   ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         Scan Phase                                       │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  收集对象信息 → 去重 → 排序 → 写入 GCWindow                      │   │
│  └─────────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         Filter Phase                                     │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  Bloom Filter 粗过滤 → Snapshot/PITR 细过滤 → 分离可GC/不可GC   │   │
│  └─────────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         Delete Phase                                     │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  批量删除 → 并发执行 → 错误处理                                  │   │
│  └─────────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         Merge Phase                                      │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  合并 Checkpoint → 更新水位线 → 清理旧文件                       │   │
│  └─────────────────────────────────────────────────────────────────┘   │

```

## 2. 扫描阶段详解

### 2.1 数据收集流程

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      scanCheckpointsLocked                               │
└─────────────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  1. 遍历 Checkpoint 列表                                                 │
│     for each checkpoint in checkpointEntries:                           │
│         reader = getCkpReader(checkpoint)                               │
│         processCkpData(checkpoint, reader)  // 更新快照元数据            │

                              │

│  2. 对象去重                                                             │
│     objects: map[objectName]map[tableID]*ObjectEntry                    │

                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  3. 数据排序                                                             │
│     sortOneBatch: 按主键（对象名）排序                                   │

                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  4. 写入 Sinker                                                          │
│     - 内存缓存 + S3 文件                                                 │

└─────────────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  5. 保存快照元数据                                                       │
│     - 快照文件: meta_{start}_{end}.snap                                 │

└─────────────────────────────────────────────────────────────────────────┘
```

### 2.2 对象收集逻辑

```go
func collectObjectsFromCheckpointData(
    ctx context.Context, 
    ckpReader *logtail.CKPReader, 
    objects map[string]map[uint64]*ObjectEntry,
) {
    ckpReader.ForEachRow(ctx, func(
        account uint32,
        dbid, tid uint64,
        objectType int8,
        stats objectio.ObjectStats,
        createTS, deleteTS types.TS,
        rowID types.Rowid,
    ) error {
        name := stats.ObjectName().String()
        if objects[name] == nil {
            objects[name] = make(map[uint64]*ObjectEntry)
        }
        objects[name][tid] = &ObjectEntry{
            stats:    &stats,
            createTS: createTS,
            dropTS:   deleteTS,
            db:       dbid,
            table:    tid,
        }
        return nil
    })
}
```

## 3. 过滤阶段详解

### 3.1 两阶段过滤流程

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         过滤阶段                                         │
└─────────────────────────────────────────────────────────────────────────┘

输入: GCWindow.files (所有扫描到的对象)

┌─────────────────────────────────────────────────────────────────────────┐
│  阶段1: 粗过滤 (Bloom Filter)                                            │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  1. 从全局 Checkpoint 构建 Bloom Filter                          │   │
│  │  2. 对每个对象检查是否在 Bloom Filter 中                         │   │
│  │  3. 不在 → 标记为可GC候选                                        │   │
│  │  4. 在 → 保留（不可GC）                                          │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  输出:                                                                   │
│  - cannotGC: 在全局 Checkpoint 中的对象                                 │
│  - canGC: 不在全局 Checkpoint 中的对象（候选）                          │
└─────────────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  阶段2: 细过滤 (Snapshot/PITR)                                           │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  对 canGC 中的每个对象:                                          │   │
│  │  1. 检查表是否仍存在                                             │   │
│  │  2. 检查是否被快照引用                                           │   │
│  │  3. 检查是否被 PITR 保护                                         │   │
│  │  4. 检查 ISCP 表约束                                             │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  输出:                                                                   │
│  - finalCannotGC: 被保护的对象                                          │
│  - finalCanGC: 确定可删除的对象                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 3.2 快照引用检查

```go
// logtail.ObjectIsSnapshotRefers 检查逻辑
func ObjectIsSnapshotRefers(
    stats *objectio.ObjectStats,
    pitr *types.TS,           // PITR 时间点
    createTS *types.TS,       // 对象创建时间
    dropTS *types.TS,         // 对象删除时间
    snapshots []types.TS,     // 快照时间点列表
) bool {
    // 1. 如果对象未删除，不能GC
    if dropTS.IsEmpty() {
        return true
    }
    
    // 2. 检查 PITR 保护
    if pitr != nil && !pitr.IsEmpty() {
        if createTS.LE(pitr) && (dropTS.IsEmpty() || dropTS.GT(pitr)) {
            return true  // 被 PITR 保护
        }
    }
    
    // 3. 检查快照保护
    for _, snap := range snapshots {
        if createTS.LE(&snap) && (dropTS.IsEmpty() || dropTS.GT(&snap)) {
            return true  // 被快照保护
        }
    }
    
    return false  // 可以 GC
}
```

## 4. 删除阶段详解

### 4.1 删除流程

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         删除阶段                                         │
└─────────────────────────────────────────────────────────────────────────┘

输入: filesToGC []string (可删除的文件名列表)

┌─────────────────────────────────────────────────────────────────────────┐
│  1. 去重                                                                 │
│     使用 map 去除重复的文件名                                            │
│     (同一对象可能被多个表引用，会出现多次)                               │
└─────────────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  2. 分批                                                                 │
│     将文件列表分成多个批次                                               │
│     每批最多 deleteBatchSize (默认 1000) 个文件                         │
└─────────────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  3. 并发删除                                                             │
│     使用 workerNum (默认 4) 个 worker 并发执行                          │
│     每个 worker 处理一个批次                                             │
│     使用 semaphore 控制并发数                                            │
└─────────────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  4. 错误处理                                                             │
│     - ErrFileNotFound: 忽略（文件可能已被删除）                         │
│     - 其他错误: 返回错误                                                 │
└─────────────────────────────────────────────────────────────────────────┘
```

### 4.2 并发删除实现

```go
func (g *Deleter) DeleteMany(ctx context.Context, taskName string, paths []string) error {
    // 分批
    var batches [][]string
    for i := 0; i < len(paths); i += g.deleteBatchSize {
        end := min(i + g.deleteBatchSize, len(paths))
        batches = append(batches, paths[i:end])
    }
    
    // 并发删除
    var wg sync.WaitGroup
    errCh := make(chan error, len(batches))
    semaphore := make(chan struct{}, g.workerNum)
    
    for _, batch := range batches {
        semaphore <- struct{}{}  // 获取信号量
        wg.Add(1)
        go func(paths []string) {
            defer wg.Done()
            defer func() { <-semaphore }()  // 释放信号量
            
            if err := g.deleteBatch(ctx, taskName, paths); err != nil {
                if !moerr.IsMoErrCode(err, moerr.ErrFileNotFound) {
                    errCh <- err
                }
            }
        }(batch)
    }
    
    wg.Wait()
    close(errCh)
    
    // 检查错误
    for err := range errCh {
        if err != nil {
            return err
        }
    }
    return nil
}
```

## 5. 合并阶段详解

### 5.1 Checkpoint 合并流程

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         合并阶段                                         │
└─────────────────────────────────────────────────────────────────────────┘

输入: 
- toMergeCheckpoint: 待合并的 Checkpoint 列表
- bf: Bloom Filter (包含 GCWindow 中的对象)

┌─────────────────────────────────────────────────────────────────────────┐
│  1. 加载 Checkpoint 数据                                                 │
│     for each checkpoint:                                                │
│         data = LoadCheckpointEntries(checkpoint)                        │
│         deleteFiles.append(checkpoint.metaFile)                         │
│         deleteFiles.append(checkpoint.dataFiles)                        │
└─────────────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  2. 过滤对象                                                             │
│     for each object in checkpoint:                                      │
│         if bf.Test(object.name):  // 在 GCWindow 中                     │
│             ckpData.append(object)  // 保留                             │
└─────────────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  3. 写入新 Checkpoint                                                    │
│     - 创建新的 Compacted Checkpoint                                     │
│     - 写入数据文件                                                       │
│     - 写入元数据文件                                                     │
└─────────────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────────────┐
│  4. 更新状态                                                             │
│     - 更新 Compacted Checkpoint                                         │
│     - 更新 checkpointGCWaterMark                                        │
│     - 删除旧的 Checkpoint 文件                                          │
└─────────────────────────────────────────────────────────────────────────┘
```

## 6. 元数据文件管理

### 6.1 文件类型

| 扩展名 | 描述 | 示例 |
|--------|------|------|
| `.gc` | GC 元数据文件 | `meta_t100_t200.gc` |
| `.snap` | 快照元数据文件 | `meta_t100_t200.snap` |
| `.acct` | 账户信息文件 | `meta_t100_t200.acct` |
| `.ckp` | Checkpoint 元数据 | `meta_t100_t200.ckp` |
| `.cpt` | Compacted Checkpoint | `compact_t100_t200.cpt` |

### 6.2 文件生命周期

```
创建 → 使用 → 过期 → 删除

1. 扫描时创建 GC 元数据文件
2. GC 时使用元数据文件
3. 新的扫描完成后，旧文件过期
4. 清理阶段删除过期文件
```

## 7. WAL 集成

### 7.1 WAL 写入

```go
func (c *checkpointCleaner) appendFilesToWAL(files ...string) error {
    if c.logDriver == nil {
        return nil
    }
    entry, err := wal.BuildFilesEntry(files)
    if err != nil {
        return err
    }
    _, err = c.logDriver.AppendEntry(wal.GroupFiles, entry)
    return err
}
```

### 7.2 作用

- 记录 GC 元数据文件的创建
- 支持崩溃恢复时的一致性
- 确保元数据文件不会丢失
