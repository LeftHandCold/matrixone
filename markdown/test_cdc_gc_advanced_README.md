# CDC GC 高级测试脚本使用说明

## 概述

`test_cdc_gc_advanced.py` 是一个高级的CDC GC功能测试脚本，支持：
- **多租户测试**：自动创建和管理6个租户（前缀：cdc_test）
- **多数据库多表**：每个租户下创建多个数据库，每个数据库多个表
- **混合CDC任务**：数据库级别和表级别的CDC任务
- **并发数据插入**：持续并发插入数据到所有表
- **水位监控**：定期检查水位变化，检测停滞
- **长时间运行**：循环运行，持续测试

## 功能特性

### 1. 租户管理
- 自动创建6个租户（前缀：`cdc_test_1` 到 `cdc_test_6`）
- 如果租户已存在，跳过创建
- 每个租户使用独立的admin账户

### 2. 数据库和表管理
- 每个租户下创建3个数据库（可配置）
- 每个数据库下创建3个表（可配置）
- 自动管理数据库和表的创建

### 3. CDC任务管理
- **数据库级别CDC**：随机选择70%的数据库创建数据库级别CDC任务
- **表级别CDC**：为没有CDC任务的数据库创建一个表的CDC任务
- 自动创建sink数据库

### 4. 数据插入
- 持续并发插入数据到所有表
- 每个表独立线程插入数据
- 随机数据值，模拟真实场景

### 5. 水位监控
- 定期检查所有CDC任务的水位
- 检测水位停滞（超过20分钟未更新）
- 记录水位变化历史


## 安装依赖

```bash
pip install -r test_cdc_gc_requirements.txt
```

或者直接安装：

```bash
pip install pymysql
```

## 使用方法

### 基本用法

```bash
python3 test_cdc_gc_advanced.py
```

### 自定义连接参数

```bash
export DB_HOST=127.0.0.1
export DB_PORT=6001
export DB_USER=dump
export DB_PASS=111
export ACCOUNT_ID=0
python3 test_cdc_gc_advanced.py
```

## 配置参数

脚本中的配置参数（可在代码中修改）：

```python
NUM_TENANTS = 6                    # 租户数量
TENANT_PREFIX = "cdc_test"         # 租户前缀
ADMIN_USER = "admin"               # 租户admin用户名
ADMIN_PASS = "111"                 # 租户admin密码
NUM_DATABASES_PER_TENANT = 3       # 每个租户的数据库数
NUM_TABLES_PER_DATABASE = 3        # 每个数据库的表数
WATERMARK_CHECK_INTERVAL = 60      # 检查水位间隔（秒）
WATERMARK_STALL_TIMEOUT = 1200     # 水位停滞超时（20分钟）
DATA_INSERT_INTERVAL = 10          # 数据插入间隔（秒）
```

## 测试流程

1. **初始化阶段**：
   - 检查或创建6个租户
   - 为每个租户创建数据库和表
   - 设置CDC任务（数据库级别和表级别）

2. **运行阶段**：
   - 启动数据插入线程（持续插入数据）
   - 循环执行：
     - 检查水位变化
     - 检测水位停滞
     - 等待下一次检查

3. **监控阶段**：
   - 定期输出水位状态
   - 检测异常（水位停滞）
   - 记录任务状态

## 注意事项

1. **租户创建**：
   - 需要系统管理员权限
   - 如果租户已存在，不会重复创建
   - 租户的admin密码统一为"111"（可在代码中修改）

2. **水位更新延迟**：
   - 水位更新不是实时的，需要等待
   - 脚本会定期检查水位变化
   - 如果20分钟未更新，会记录警告

3. **长时间运行**：
   - 脚本会持续运行，直到手动停止（Ctrl+C）
   - 数据插入会持续进行
   - 建议在测试环境中运行

4. **资源占用**：
   - 多个租户、数据库和表会占用资源
   - 并发数据插入会增加数据库负载
   - 建议监控数据库性能指标

5. **任务管理**：
   - 不会删除已创建的任务
   - 可以手动管理任务

## 查看CDC任务状态

测试过程中，可以查看CDC任务状态：

```sql
-- 查看所有CDC任务
SHOW CDC TASKS;

-- 查看特定租户的任务
SELECT task_id, task_name, state, err_msg 
FROM mo_catalog.mo_cdc_task 
WHERE account_id IN (
    SELECT account_id FROM mo_catalog.mo_account WHERE account_name LIKE 'cdc_test_%'
);

-- 查看水位
SELECT db_name, table_name, watermark, err_msg 
FROM mo_catalog.mo_cdc_watermark 
WHERE account_id IN (
    SELECT account_id FROM mo_catalog.mo_account WHERE account_name LIKE 'cdc_test_%'
);
```

## 停止测试

按 `Ctrl+C` 停止测试，脚本会：
- 停止数据插入线程
- 关闭数据库连接
- 输出测试总结

## 故障排查

### 问题1: 租户创建失败
```
[ERROR] 创建租户 cdc_test_1 失败
```

**解决方案**:
- 检查是否有系统管理员权限
- 检查租户名称是否已存在
- 查看数据库日志

### 问题2: 水位停滞
```
[WARNING] ⚠ 任务 xxx 表 xxx 水位停滞超过 20 分钟
```

**解决方案**:
- 检查CDC任务是否正常运行
- 查看CDC任务日志是否有错误
- 检查数据是否正常插入
- 验证CDC任务配置是否正确

### 问题3: 数据插入失败
```
[ERROR] 数据插入异常: ...
```

**解决方案**:
- 检查数据库连接是否稳定
- 检查表结构是否正确
- 减少并发线程数
- 增加插入间隔时间

## 扩展测试

如果需要修改测试场景，可以：

1. **修改配置参数**：在脚本开头修改配置常量
2. **添加新的测试逻辑**：在 `run_test_loop()` 中添加
3. **自定义水位检查**：修改 `check_watermark_stall()` 方法
